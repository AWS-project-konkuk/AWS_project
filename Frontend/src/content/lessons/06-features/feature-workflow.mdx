## 설계하고 비교할 것

공통 정의에서 두 저장소로 분기하고 정의 차이를 수정하세요.

## 실습에서 가져갈 이해

Feature Store는 피처의 일관된 제공, 벡터 검색은 관련 문서 조회, RAG는 근거를 생성 문맥에 전달하는 역할입니다. 서로 같은 기능이 아닙니다.

## 적용 조건과 한계

Feature Store를 설치하는 것만으로 정의 불일치와 미래 정보 누출이 사라지지 않습니다. 과거 예측 시점에 실제로 알 수 있었던 값만 조인하고, 온라인 갱신의 지연·실패도 관측해야 합니다.

## 전체 과정과 연결하기

오프라인 자료 생성과 온라인 갱신에 같은 피처 정의와 집계 창을 적용합니다. 학습에는 과거 시점의 값을 붙이고 추론에는 갱신된 온라인 값을 조회해 모델에 전달합니다.
