## 코드는 지난주인데 데이터는 이번 주입니다

지난주 모델 점수를 재현하려고 코드부터 v1으로 돌렸습니다. 곧바로 학습을 돌렸더니 도리어 이번 주 사진으로 새 모델을 만들었습니다. Git에서 지난주를 골랐는데, 작업 폴더는 왜 여전히 이번 주일까요?

Git 기록은 필요한 데이터의 버전을 알려 줍니다. 실제 파일은 로컬 캐시에 있으면 바로 꺼내고, 없으면 DVC 원격에서 가져옵니다.

## 서비스와 노드

실습 화면에는 GitHub, 저장소(S3), EC2 세 서비스가 있고, 시작은 현재 작업 폴더의 데이터 `v2`를 보냅니다. 처음에는 선이 하나도 연결되어 있지 않습니다. 필요한 선은 직접 연결하세요.

| 서비스 | 노드        | 하는 일                                                                                        |
| ------ | ----------- | ---------------------------------------------------------------------------------------------- |
| GitHub | 코드 저장소 | 선택한 커밋의 코드와 데이터 포인터(`.dvc`)를 내보낸다                                          |
| 저장소 | 파일        | 저장소에 있는 데이터 파일. 데이터 버전을 설정해 필요한 파일을 내보낸다                         |
| EC2    | 복원·검증   | 코드·포인터와 작업 데이터(와 파일)를 받아 복원한다. 복원 작업과 캐시 상태가 이 노드의 설정이다 |

EC2에는 앞 단원에서 쓴 **학습 실행**도 만들 수 있지만, 이번 실습의 판정에는 영향을 주지 않습니다. **버전을 알려 주는 정보**(코드·포인터)와 **실제 파일이 이동하는 경로**(파일)를 구분해서 연결하세요.

## 실습은 이 순서로 진행하세요

### 1. 필요한 선을 연결하고 Git만 v1으로 이동해 보세요

1. 코드 저장소의 출력을 복원·검증의 코드·포인터 입력에, 시작의 작업 데이터를 복원·검증의 작업 데이터 입력에, 복원·검증의 출력을 도착에 연결합니다.
2. **실습 실행**을 누릅니다. 코드 저장소는 최신 커밋 `v2`를 내보내므로 재현할 실험 v1과 다르다는 결과가 나옵니다.
3. **코드 저장소**의 커밋을 `v1`로 바꾸고 다시 실행합니다. 복원 작업이 `Git 이동만`이면 코드는 v1이지만 작업 폴더에는 기존 v2 데이터가 남습니다. 두 버전이 달라 지난 실험을 재현할 수 없고, 실행은 실패합니다.

### 2. 캐시에 v1이 있을 때 복원하세요

1. **복원·검증**을 선택하고 **로컬 캐시의 데이터**를 `캐시에 있음`으로 바꿉니다.
2. **복원 작업**에서 `dvc checkout`을 선택하고 다시 실행합니다.

필요한 파일이 내 컴퓨터의 캐시에 있으므로 원격에서 다시 받지 않습니다. 결과의 데이터 출처가 `로컬 캐시`이고 코드와 데이터가 모두 v1이면 성공입니다.

### 3. 캐시에 v1이 없을 때 복원하세요

1. **로컬 캐시의 데이터**를 `캐시에 없음`으로 바꾸고 `dvc checkout`으로 실행해 실패하는 것을 확인합니다.
2. **복원 작업**을 `dvc pull 후 복원`으로 바꿉니다. 저장소의 **파일** 출력을 복원·검증의 파일 입력에 연결해야 합니다.
3. 실행하면 파일의 데이터 버전이 포인터와 다르다는 결과가 나옵니다. **파일**의 데이터 버전을 `v1`로 바꿔 필요한 파일을 내보내게 하고 다시 실행합니다.

실행을 마치면 결과 패널의 **관찰할 조건** 세 가지(Git만 이동한 불일치, 원격 복원, 캐시 복원)가 모두 표시되고, 이해 확인에 답하면 실습이 완료됩니다.

## 실제 학습 전에 네 가지를 기록하세요

| 확인할 것 | 기록 예                           |
| --------- | --------------------------------- |
| 코드      | Git 커밋                          |
| 데이터    | DVC 해시 또는 Lakehouse 스냅샷 ID |
| 학습 설정 | 학습 횟수, 학습률, 난수 시드      |
| 실행 환경 | 컨테이너 이미지와 라이브러리 버전 |

코드와 데이터가 모두 v1이면 입력 복원은 끝났습니다. 실제 모델까지 재현하려면 설정과 실행 환경을 맞춘 뒤 결과 점수도 비교해야 합니다. 이 실습은 복원 흐름을 설명하는 모형이므로 실제 파일 다운로드나 모델 학습을 실행하지는 않습니다.

<LessonSummary>

지난 실험으로 돌아가려면 Git에서 코드와 데이터 이름표를 선택하고, 이름표가 가리키는 실제 데이터를 작업 공간에 복원해야 합니다. 캐시에 파일이 있으면 `dvc checkout`으로 재사용하고, 없으면 `dvc pull`로 원격에서 가져옵니다. 코드와 데이터 버전이 일치한 뒤에는 학습 설정과 실행 환경까지 확인하고 결과를 비교해야 같은 실험을 재현할 수 있습니다.
