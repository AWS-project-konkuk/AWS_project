## 지난주 모델을 다시 만들어 봅시다

이번 실습의 목표는 **지난주 코드(v1)가 지난주 데이터(v1)를 읽도록 맞추는 것**입니다. 현재 작업 폴더에는 이번 주 데이터(v2)가 있습니다. Git에서 v1 코드를 선택해도 큰 데이터 파일까지 자동으로 바뀌지는 않습니다.

Git 기록은 필요한 데이터의 버전을 알려 줍니다. 실제 파일은 로컬 캐시에 있으면 바로 꺼내고, 없으면 DVC 원격에서 가져옵니다.

## 먼저 재현에 필요한 조건을 확인하세요

<Activity />

## 다섯 노드의 역할

| 노드           | 하는 일                          |
| -------------- | -------------------------------- |
| Git 커밋       | 지난주 코드와 데이터 이름표 선택 |
| DVC 원격       | 팀이 공유한 실제 데이터 보관     |
| 로컬 캐시      | 내 컴퓨터에 데이터 보관          |
| 작업 공간 복원 | 학습에서 사용할 파일 꺼내기      |
| 실험 재현 확인 | 코드와 데이터가 맞는지 확인      |

**버전을 알려 주는 정보**와 **실제 파일이 이동하는 경로**를 구분해서 노드를 연결하세요.

## 실습은 이 순서로 진행하세요

### 1. Git만 v1으로 이동해 보세요

1. **재현할 실험 버전**에서 `v1`을 선택합니다.
2. **복원 작업**은 `Git 이동만`으로 둡니다.
3. 실행한 뒤 Git 버전과 작업 데이터 버전을 비교합니다.

Git 기록은 v1로 바뀌지만 작업 폴더에는 기존 v2 데이터가 남습니다. 이 상태는 코드와 데이터의 버전이 다르므로 지난 실험을 재현할 수 없습니다.

### 2. 캐시에 v1이 있을 때 복원하세요

1. **로컬 캐시의 v1**을 `캐시에 있음`으로 바꿉니다.
2. **복원 작업**에서 `dvc checkout`을 선택합니다.
3. 다시 실행해 작업 데이터가 v1으로 바뀌는지 확인합니다.

필요한 파일이 내 컴퓨터의 캐시에 있으므로 원격에서 다시 받을 필요가 없습니다. `dvc checkout`은 캐시의 v1 데이터를 작업 폴더에 꺼냅니다.

### 3. 캐시에 v1이 없을 때 복원하세요

1. **로컬 캐시의 v1**을 `캐시에 없음`으로 바꿉니다.
2. 먼저 `dvc checkout`을 선택해 캐시가 없을 때의 결과를 확인합니다.
3. **복원 작업**을 `dvc pull 후 복원`으로 바꾸고 다시 실행합니다.

이 경우에는 DVC 원격에서 v1 파일을 받아 캐시에 저장한 뒤 작업 폴더에 반영합니다. 결과에서 코드와 작업 데이터가 모두 v1인지 확인하세요.

### 4. 노드에서 파일의 이동 경로를 확인하세요

노드를 연결할 때는 다음 두 관계를 구분합니다.

- `Git 커밋 → 로컬 캐시`: 어떤 데이터 버전이 필요한지 알려 주는 이름표
- `DVC 원격 → 로컬 캐시 → 작업 공간 복원`: 실제 데이터가 이동하는 경로
- `작업 공간 복원 → 실험 재현 확인`: 코드와 데이터 버전이 맞는지 검사

Git 커밋에서 로컬 캐시로 이어지는 선은 큰 파일이 Git에서 내려온다는 뜻이 아닙니다. Git의 `.dvc` 파일이 캐시에서 찾아야 할 데이터의 해시를 알려 준다는 뜻입니다.



## 실제 학습 전에 네 가지를 기록하세요

| 확인할 것 | 기록 예                           |
| --------- | --------------------------------- |
| 코드      | Git 커밋                          |
| 데이터    | DVC 해시 또는 Lakehouse 스냅샷 ID |
| 학습 설정 | 학습 횟수, 학습률, 난수 시드      |
| 실행 환경 | 컨테이너 이미지와 라이브러리 버전 |

코드와 데이터가 모두 v1이면 입력 복원은 끝났습니다. 실제 모델까지 재현하려면 설정과 실행 환경을 맞춘 뒤 결과 점수도 비교해야 합니다. 이 실습은 복원 흐름을 설명하는 모형이므로 실제 파일 다운로드나 모델 학습을 실행하지는 않습니다.

<LessonSummary>

지난 실험으로 돌아가려면 Git에서 코드와 데이터 이름표를 선택하고, 이름표가 가리키는 실제 데이터를 작업 공간에 복원해야 합니다. 캐시에 파일이 있으면 `dvc checkout`으로 재사용하고, 없으면 `dvc pull`로 원격에서 가져옵니다. 코드와 데이터 버전이 일치한 뒤에는 학습 설정과 실행 환경까지 확인하고 결과를 비교해야 같은 실험을 재현할 수 있습니다.
