## 이번 미션

새 이미지는 v2인데 Pod가 v1을 실행하고 있습니다. Pod 한 개가 사라져도 같은 환경을 다시 만들고 요청을 이어가야 합니다.

## 설계하고 비교할 것

이미지·원하는 상태·실제 요청을 구분해 연결하세요. 버전 불일치와 장애 상태를 관찰한 뒤 같은 이미지로 두 Pod를 준비하고 응답을 확인하세요.

## 실습에서 가져갈 이해

이미지는 실행 템플릿, Pod는 실행 단위, Deployment는 원하는 수를 유지하는 관리자, Service는 요청 경로입니다.

## 적용 조건과 한계

컨테이너는 호스트 커널을 공유합니다. 이미지가 같아도 GPU 드라이버나 외부 설정이 다를 수 있습니다. Deployment의 복제본 유지와 HPA의 부하 기반 확장은 별도 기능입니다.

## 전체 과정과 연결하기

선언된 이미지 버전으로 Pod를 만들고 복제본 수를 맞춘 뒤, Service의 선택 조건과 준비 상태를 확인해 요청을 전달합니다. Pod 교체 뒤에도 같은 환경과 요청 경로가 이어져야 합니다.
