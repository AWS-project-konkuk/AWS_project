## 개념 이해

이미지는 코드·의존성·파일 시스템 등을 담은 실행 템플릿입니다. 컨테이너는 이미지를 바탕으로 실행하는 격리된 프로세스입니다. 같은 이미지로 여러 컨테이너를 만들 수 있으며 이미지가 실행 중인 서버라는 뜻은 아닙니다.

> **연결 전에 예측하기** — 이미지는 실행 중인 컨테이너가 아닙니다. 같은 이미지에서 두 컨테이너를 시작하는 분기를 확인하세요.

연결을 따라가며 확인한 자료는 **이미지 v1 사용 · 이미지 v1 사용**입니다. 배포할 때는 이미지 버전을 고정하고 외부 데이터·환경 변수·마운트도 확인해야 합니다. 같은 이미지라도 외부 입력이 바뀌면 결과가 달라질 수 있습니다.

## 관찰한 결과 해석하기

이미지는 읽기 전용 레이어를 재사용하고 컨테이너마다 쓰기 가능한 상태를 갖습니다. 일관된 실행 환경을 배포하는 데 유용하지만 호스트의 커널과 자원에 의존하므로 모든 환경 차이를 없애는 것은 아닙니다.
