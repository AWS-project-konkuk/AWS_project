새 모델을 일부 사용자에게 먼저 보내면? 신규 모델의 사용자 트래픽 비율을 점진적으로 늘립니다.

그림의 **기존 모델**, **일부 실제 요청**, **새 모델**에 주목해 보세요. 실제 사용자 요청의 일부를 새 모델로 보내면 영향을 제한하며 지연·오류·품질을 관찰할 수 있습니다.

## 개념 이해

Canary는 일부 실제 사용자 요청을 새 버전으로 전달해 영향을 제한하며 관측합니다. 지연·오류·품질을 확인하고 비율을 늘리거나 기존 버전으로 되돌립니다.

> **연결 전에 예측하기** — Canary는 실제 요청 일부를 새 모델로 보냅니다. 요청 복제만 하는 Shadow와 무엇이 다른지 생각해보세요.

<NodeExample />

연결을 따라가며 확인한 자료는 **실제 요청 90건 · 실제 요청 10건**입니다. 새 모델의 응답을 사용자가 받는다는 점을 고려해 비율과 중단 기준을 정합니다. 작은 표본의 수치만으로 전체 사용자 품질을 단정하지 마세요.

## 관찰한 결과 해석하기

Canary의 신규 모델 응답은 실제 사용자에게 전달됩니다. 비율을 낮춰도 영향이 0은 아닙니다. 이 활동은 100개 요청을 고정적으로 분배하며 통계적 품질 검증 전체를 재현하지 않습니다.

## 적용 조건과 한계

전송 프로토콜 선택은 모델 품질을 바꾸지 않습니다. Shadow는 새 모델의 응답을 사용자에게 보내지 않고, Canary는 일부 사용자에게 실제로 보냅니다. 전환과 승격은 별도 판단입니다.

## 전체 과정과 연결하기
