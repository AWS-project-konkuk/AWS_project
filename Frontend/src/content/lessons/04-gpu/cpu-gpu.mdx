## 개념 이해

CPU는 복잡한 제어와 다양한 작업을 처리하고 GPU는 많은 연산을 병렬로 처리하도록 설계되어 있습니다. 행렬 계산처럼 비슷한 연산이 반복되는 학습에서는 GPU의 처리량이 유리합니다. CPU도 병렬 처리가 가능하며 아래의 순차 CPU는 비교를 위한 단순 모델입니다.

| 구분 | 강점                      | 추가 고려           |
| ---- | ------------------------- | ------------------- |
| CPU  | 다양한 제어·작업          | 이 활동은 순차 예시 |
| GPU  | 비슷한 연산의 병렬 처리량 | 준비·전송 비용      |

## 관찰한 결과 해석하기

작업 수가 작으면 GPU 실행 준비나 전송 비용이 처리 이득보다 클 수 있습니다. 작업 수가 커질수록 같은 시간에 처리하는 양이 중요해집니다. 이 실험은 실제 하드웨어 벤치마크가 아니며 GPU의 개별 연산이 항상 더 느리거나 빠르다는 뜻도 아닙니다.

## 적용 조건과 한계

혼합 정밀도가 전체 메모리를 항상 절반으로 줄이지는 않습니다. 일반 데이터 병렬은 전체 모델 상태를 GPU마다 복제합니다. 모델 상태를 나누는 전략과 통신 비용을 함께 비교해야 합니다.

## 전체 과정과 연결하기

CPU는 다양한 제어 흐름에, GPU는 많은 자료에 유사한 연산을 병렬 적용하는 데 적합합니다. GPU 사용에는 준비·메모리 이동 비용이 있어 작업 규모에 따라 전체 실행 시간이 달라집니다.
