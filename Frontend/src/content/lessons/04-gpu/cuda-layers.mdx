## 개념 이해

CUDA는 NVIDIA GPU에서 병렬 연산을 실행하기 위한 플랫폼입니다. 프레임워크가 모든 하드웨어 제어를 직접 하지 않고 연산 라이브러리·런타임·드라이버를 통해 GPU를 사용합니다. 다른 제조사의 가속기에는 다른 소프트웨어 생태계가 있습니다.

## 관찰한 결과 해석하기

cuBLAS는 선형대수, cuDNN은 딥러닝 연산, NCCL은 여러 GPU의 통신을 지원합니다. 패키지 하나의 버전만 맞춘다고 실행 환경 전체의 호환이 보장되지는 않습니다. 이 페이지에서는 설치 명령보다 각 계층의 역할을 익힙니다.

## 계층으로 읽기 · 호출과 실행

PyTorch 등 프레임워크 → CUDA 라이브러리·Runtime → Driver → GPU 순으로 역할을 나눕니다. 소프트웨어 호출 경로는 CUDA의 Grid·Block·Thread라는 커널 실행 조직이나 Global·Shared·Register라는 메모리 계층과 같은 분류가 아닙니다.

## 적용 조건과 한계

혼합 정밀도가 전체 메모리를 항상 절반으로 줄이지는 않습니다. 일반 데이터 병렬은 전체 모델 상태를 GPU마다 복제합니다. 모델 상태를 나누는 전략과 통신 비용을 함께 비교해야 합니다.

## 전체 과정과 연결하기

프레임워크의 연산은 연산 라이브러리·런타임·드라이버 같은 계층을 통해 NVIDIA GPU에서 수행됩니다. 각 계층이 호환되어야 프로그램이 장치를 사용하고 필요한 연산을 실행할 수 있습니다.
