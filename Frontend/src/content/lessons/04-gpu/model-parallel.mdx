## 문제 상황과 전체 맥락

모델을 한 GPU에 담을 수 없다면? 모델의 서로 다른 부분을 GPU에 배치합니다.

## 개념 이해

큰 모델이 한 GPU에 들어가지 않으면 모델을 나눠 여러 GPU에 배치할 수 있습니다. 여기서는 앞 레이어와 뒤 레이어를 나누는 방식을 모델 병렬의 예로 사용합니다. 중간 활성값이 GPU 사이를 이동해야 다음 부분의 계산이 진행됩니다.

## 관찰한 결과 해석하기

메모리를 나눠 쓸 수 있어도 단순한 레이어 분할만으로 GPU들이 항상 동시에 일하지는 않습니다. 앞부분 결과를 기다리는 시간과 장치 간 전송 비용이 생깁니다. 파이프라인 병렬은 여러 마이크로 배치를 겹쳐 이런 대기를 줄이는 별도 확장입니다.

## 적용 조건과 한계

혼합 정밀도가 전체 메모리를 항상 절반으로 줄이지는 않습니다. 일반 데이터 병렬은 전체 모델 상태를 GPU마다 복제합니다. 모델 상태를 나누는 전략과 통신 비용을 함께 비교해야 합니다.

## 전체 과정과 연결하기

모델의 앞쪽과 뒤쪽 레이어를 다른 GPU에 배치하면 각 장치가 전체 모델을 보관할 필요가 줄어듭니다. 앞부분의 결과 활성값이 다음 장치로 전달되어야 뒤 연산을 진행할 수 있습니다.
