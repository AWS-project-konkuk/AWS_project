## 개념과 동작 원리

VRAM 용량은 모델·활성값·그래디언트·옵티마이저 상태가 들어갈 공간을 제한하고 메모리 대역폭은 장치 안의 자료 이동에 영향을 줍니다. 정밀도별 연산 성능과 GPU 간 통신도 구분합니다. 특정 모델 크기를 VRAM 용량 하나로 고정해 추천하지 않습니다.

## 자료와 요청의 흐름

작은 마이크로 배치로 forward·backward를 여러 번 수행하고 그래디언트를 누적한 뒤 optimizer step을 수행할 수 있습니다. 단일 장치의 유효 배치는 마이크로 배치 × 누적 횟수로 이해합니다. 큰 배치와 완전히 같은 수치 결과를 항상 보장하지 않으며 정규화·학습률·처리량도 확인합니다.

## 비교와 한계

혼합 정밀도가 전체 메모리를 항상 절반으로 줄이지는 않습니다. 일반 데이터 병렬은 전체 모델 상태를 GPU마다 복제합니다. 모델 상태를 나누는 전략과 통신 비용을 함께 비교해야 합니다.

## 전체 과정과 연결

GPU가 빠르다는 설명만으로는 자원 선택을 할 수 없습니다. 작업 크기, 모델과 활성값의 메모리, 데이터 공급 속도, 장치 간 통신을 함께 고려해야 합니다. 모델이 한 GPU에 들어가는지와 계산을 더 빨리 끝내려는지는 다른 질문이며, 이 차이가 병렬화 전략을 결정합니다.
