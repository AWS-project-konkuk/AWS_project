## 개념 이해

Shadow는 운영 요청을 새 모델에도 복제해 실행 결과를 비교합니다. 사용자에게는 기존 모델의 응답을 전달하고 신규 응답은 관측·분석에 사용합니다.

## 관찰한 결과 해석하기

복제 요청을 처리할 추가 자원이 필요하며 부수 효과가 있는 요청의 취급에도 주의해야 합니다. Shadow 비교를 마쳤다고 자동으로 신규 모델이 운영 트래픽을 받는 것은 아닙니다. 전환은 별도 결정입니다.

## 적용 조건과 한계

전송 프로토콜 선택은 모델 품질을 바꾸지 않습니다. Shadow는 새 모델의 응답을 사용자에게 보내지 않고, Canary는 일부 사용자에게 실제로 보냅니다. 전환과 승격은 별도 판단입니다.
