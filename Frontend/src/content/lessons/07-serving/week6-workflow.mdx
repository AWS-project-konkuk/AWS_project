## 이번 미션

신규 모델이 아직 준비되지 않았습니다. 전환 비율과 Shadow 복제 비율을 혼동하면 어떤 요청이 영향을 받을까요?

## 설계하고 비교할 것

요청 경로·사용자 응답·비교 로그를 각각 연결하세요. 중단 배포 실패와 안전한 전략을 비교하고 신규 모델의 실제 응답 수를 확인하세요.

## 실습에서 가져갈 이해

Canary의 신규 응답은 사용자에게 전달됩니다. Shadow는 복제 요청을 비교하지만 사용자에게는 기존 모델의 응답을 전달합니다.

## 적용 조건과 한계

전송 프로토콜 선택은 모델 품질을 바꾸지 않습니다. Shadow는 새 모델의 응답을 사용자에게 보내지 않고, Canary는 일부 사용자에게 실제로 보냅니다. 전환과 승격은 별도 판단입니다.

## 전체 과정과 연결하기

새 버전이 요청을 받을 준비가 됐는지 확인한 뒤 배포 전략에 맞게 경로를 구성합니다. Canary의 전환 비율은 실제 응답 대상을, Shadow의 복제 비율은 관측용 추가 실행을 바꿉니다.
