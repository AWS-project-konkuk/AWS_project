## 개념 이해

VM은 하이퍼바이저 위에 게스트 운영체제와 커널을 갖습니다. 컨테이너는 프로세스를 격리하고 호스트 커널을 공유합니다. 그래서 이미지 재사용과 시작 비용에 장점이 있지만 격리 경계와 커널 호환 조건도 다릅니다.

| 구분     | 커널             | 실행 경계                 |
| -------- | ---------------- | ------------------------- |
| VM       | 게스트별 커널    | 가상 하드웨어·게스트 OS   |
| 컨테이너 | 호스트 커널 공유 | 격리된 프로세스·자원 제한 |
