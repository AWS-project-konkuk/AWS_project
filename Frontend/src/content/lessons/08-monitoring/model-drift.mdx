## 개념 이해

Data Drift는 입력 분포의 변화이고 Concept Drift는 입력과 정답 사이 관계의 변화입니다. 입력 분포가 바뀌었다고 반드시 품질이 떨어졌다는 뜻은 아니며 품질 저하가 입력 분포 변화로만 생기는 것도 아닙니다.

## Data Drift와 Concept Drift 구분

Data Drift는 입력 분포 P(X)의 변화입니다. Concept Drift는 같은 입력에서 정답의 관계 P(Y|X)가 바뀌는 현상입니다. 리뷰 문장 길이가 달라진 것과 같은 표현을 고객이 평가하는 기준이 달라진 것은 구분합니다. 입력 통계만으로 Concept Drift를 확정하지 않고 정답이나 업무 결과를 추가로 확인합니다.

## 적용 조건과 한계

입력 분포 변화가 반드시 정확도 하락을 뜻하지는 않습니다. 정답이 늦게 오는 서비스에서는 품질 확인도 지연됩니다. 지표만으로 개별 요청의 원인을 알기 어려우므로 로그·트레이스와 함께 조사합니다.

## 전체 과정과 연결하기

Data Drift는 입력 분포의 변화이고 Concept Drift는 입력과 정답의 관계 변화입니다. 입력 통계와 정답이 있는 표본을 함께 관찰해야 변화가 실제 예측 품질과 어떻게 연결되는지 판단할 수 있습니다.
