## 모델을 레이어별로 나눴는데 한 층이 너무 크다면?

모델을 레이어별로 나눠 GPU 두 장에 배치했습니다. 그런데 유독 큰 레이어 하나가 두 GPU 어디에도 들어가지 않습니다. 장치를 나누는 데는 성공했는데 학습은 그 한 층에서 멈춥니다. 레이어의 계산을 둘로 나눠서 각 GPU가 처리한다면, 부분 결과를 어떻게 다시 하나로 합칠까요?

## 개념 이해

**텐서 병렬**(Tensor Parallelism)은 하나의 레이어 **안에** 있는 큰 행렬 연산을 여러 GPU에 나누는 방법입니다. 모델 병렬 계열의 한 방식이지만, 레이어를 앞뒤로 나누는 파이프라인 병렬과 달리 레이어 내부를 더 잘게 나눕니다. GPT·LLaMA 같은 LLM은 레이어 하나의 가중치 행렬도 매우 커서, 대규모 학습에서 핵심적인 역할을 합니다.

행렬 곱셈 `Y = X·A`는 두 가지 방향으로 나눌 수 있습니다.

| 분할 방향                                     | 각 GPU가 계산하는 것       | 결과를 합치는 방법         |
| --------------------------------------------- | -------------------------- | -------------------------- |
| 열 분할: `A = [A1 \| A2]`                     | `Y1 = X·A1`, `Y2 = X·A2`   | 이어 붙이기 (`[Y1 \| Y2]`) |
| 행 분할: `A = [A1 ; A2]`, 입력도 `[X1 \| X2]` | `Y1 = X1·A1`, `Y2 = X2·A2` | 더하기 (`Y = Y1 + Y2`)     |

Megatron-LM은 Transformer의 MLP 블록에 이 두 방식을 이어 붙였습니다.

<Figure
  src="images/lessons/05-gpu/tensor-parallel/mechanism.svg"
  alt="입력 X를 두 GPU가 모두 가지고, 첫 번째 가중치 A를 열 방향으로 A1과 A2로 나누어 Y1과 Y2를 계산하고 GeLU를 적용한 뒤, 두 번째 가중치 B를 행 방향으로 B1과 B2로 나누어 부분합 Z1과 Z2를 만들고 All-Reduce로 더하는 흐름"
  caption="층 중간에는 통신이 없고, 끝에서 All-Reduce 한 번으로 부분합을 더합니다."
/>

1. 첫 번째 가중치 A를 **열 방향**으로 나눕니다. 각 GPU는 전체 입력 X로 자기 몫 `Y_i = GeLU(X·A_i)`를 계산합니다. GeLU는 원소별 연산이라 GPU마다 따로 적용해도 됩니다.
2. 두 번째 가중치 B를 **행 방향**으로 나눕니다. 각 GPU는 자기가 가진 `Y_i`로 `Z_i = Y_i·B_i`를 계산합니다.
3. **All-Reduce**로 `Z = Z1 + Z2`를 구합니다.

이렇게 하면 MLP 한 블록에서 순전파 통신이 한 번이면 됩니다. Attention 블록도 헤드를 GPU별로 나누는 같은 방식으로 처리하므로, Transformer 레이어 하나마다 순전파에서 두 번(역전파에서도 두 번) All-Reduce가 일어납니다.

## 관찰한 결과 해석하기

같은 작업을 데이터 병렬·모델 병렬 페이지와 비교하세요. 특히 통신 비용을 0에서 크게 바꿔 보며 실행 시간이 어떻게 달라지는지 확인합니다.

<Activity />

텐서 병렬은 메모리와 연산을 모두 나눌 수 있지만, **레이어마다** 통신이 반복됩니다. 그래서 통신 비용이 큰 환경에서 GPU만 추가하면 오히려 느려질 수 있습니다. 실제로는 NVLink로 묶인 한 노드 안의 GPU(보통 8장 이하)끼리만 텐서 병렬을 쓰고, 노드 사이는 파이프라인·데이터 병렬로 확장합니다.

## 적용 조건과 한계

- **빠른 GPU 간 연결이 필수**: 레이어마다 All-Reduce가 일어나므로 PCIe만으로 연결된 GPU에서는 효율이 크게 떨어집니다.
- **분할 수의 제약**: 히든 크기와 Attention 헤드 수가 GPU 수로 나누어떨어져야 합니다.
- **조합(3D 병렬)**: 대규모 LLM 학습은 텐서 병렬(노드 안) × 파이프라인 병렬(노드 사이) × 데이터 병렬(전체)을 함께 씁니다. 세 전략은 서로 배타적인 선택이 아닙니다.
- 코드 구현이 복잡하므로 직접 작성하기보다 Megatron-LM, DeepSpeed, PyTorch의 Tensor Parallel API 같은 도구를 사용합니다.

## 전체 과정과 연결하기

텐서 병렬은 한 레이어의 큰 행렬 연산을 여러 GPU에 나누고 부분 결과를 이어 붙이거나 더해 결합합니다. 레이어 전체를 앞뒤 장치에 배치하는 파이프라인 병렬과는 분할 단위가 다르며, 메모리 절감과 연산 분산의 이득을 레이어마다 반복되는 통신 비용과 비교해 선택합니다.

<Callout title="판단할 때 확인하기">

레이어 안에서도 통신이 반복되므로 GPU 간 연결(NVLink·PCIe)과 통신량을 먼저 확인합니다.

</Callout>

<LessonSummary>

텐서 병렬은 한 레이어 안의 행렬을 열 또는 행 방향으로 나누어 여러 GPU가 동시에 계산하게 합니다. Megatron-LM 방식은 열 분할 뒤 행 분할을 이어 붙여 블록 끝에서 All-Reduce 한 번으로 부분합을 더합니다. 메모리와 연산을 모두 나눌 수 있지만 레이어마다 통신이 반복되어, 빠르게 연결된 노드 안의 GPU에 적합합니다.
