## 이번 미션

학습 상태가 24GiB인 모델을 16GiB GPU 두 장에서 실행하려 합니다. 데이터 병렬로 나누었는데도 OOM이 발생합니다.

## 설계하고 비교할 것

모델·데이터를 할당하고 워커의 출력을 연결하세요. 데이터 병렬의 실패를 관찰한 뒤 레이어 또는 텐서 분할로 메모리를 맞추고 통신 비용을 비교하세요.

## 실습에서 가져갈 이해

GPU 수의 합계와 한 장에 필요한 메모리는 다릅니다. 무엇을 분할하고 어떤 결과를 주고받는지가 전략을 결정합니다.

## 적용 조건과 한계

혼합 정밀도가 전체 메모리를 항상 절반으로 줄이지는 않습니다. 일반 데이터 병렬은 전체 모델 상태를 GPU마다 복제합니다. 모델 상태를 나누는 전략과 통신 비용을 함께 비교해야 합니다.
