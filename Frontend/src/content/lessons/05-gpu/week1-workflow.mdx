## 32GiB가 있는데 24GiB 모델은 왜 안 들어갈까요?

학습에 24GiB가 필요하고, GPU는 16GiB짜리 두 장입니다. 합계가 32GiB라 넉넉하다고 생각했는데 첫 실행에서 메모리 오류가 뜹니다. 두 장을 꽂았는데 왜 한 장의 한도를 넘지 못했을까요?

## 이번 미션

학습 상태(가중치·기울기·옵티마이저 상태)가 24GiB인 모델을 16GiB GPU 두 장에서 학습하려 합니다. 처음에는 데이터 병렬로 나누었는데 OOM이 발생합니다. VRAM 합계는 32GiB로 충분해 보이는데 왜 실패할까요?

## 설계하고 비교할 것

실습은 **전체 서비스 → EC2 · GPU 서버 → 분산 학습** 순서의 트리로 되어 있습니다. 분산 학습 안에 GPU A·GPU B 워커와 결과 동기화 노드가 있습니다.

1. 출발의 학습 배치·모델 출력을 두 워커에 연결하고, 두 워커의 기울기를 결과 동기화에, 체크포인트를 도착에 연결합니다.
2. 그대로 실행해 데이터 병렬의 OOM을 확인합니다.
3. **분산 학습**을 선택해 설정의 분산 전략과 GPU 간 연결을 바꿉니다. 노드는 그대로 두고 처리 방식만 바뀝니다.

| 전략                    | GPU 한 장의 학습 상태 | 주고받는 자료                     | 이 미션에서               |
| ----------------------- | --------------------- | --------------------------------- | ------------------------- |
| 데이터 병렬             | 24GiB (전체 복제)     | step마다 기울기                   | 16GiB를 넘어 OOM          |
| 모델 병렬 (레이어 분할) | 약 12GiB              | 경계 레이어의 활성값·기울기       | 들어감, GPU가 번갈아 대기 |
| 텐서 병렬               | 약 12GiB              | 레이어마다 부분 결과 (All-Reduce) | 들어감, 통신 비용에 민감  |

통신 비용을 크게 바꾸어 보면 두 분할 전략의 차이가 드러납니다. 레이어 분할은 경계에서만 통신하므로 통신 비용에 덜 민감하지만 대기가 생기고, 텐서 분할은 두 GPU가 동시에 일하지만 레이어마다 통신합니다.

## 실습에서 가져갈 이해

GPU 수의 합계와 한 장에 필요한 메모리는 다릅니다. 무엇을 분할하고 어떤 결과를 주고받는지가 전략을 결정합니다.

실무에서는 이 상황에 **ZeRO-3·FSDP** 같은 방법도 자주 씁니다. 겉보기에는 데이터 병렬이지만 가중치·기울기·옵티마이저 상태를 GPU마다 나누어 갖고, 계산할 레이어의 가중치만 그때그때 모아서 씁니다. 장치당 상태를 줄이는 대신 통신이 늘어난다는 점에서 위 표의 분할 전략과 같은 트레이드오프를 가집니다.

## 적용 조건과 한계

- 이 실습의 12GiB는 모델 상태를 정확히 절반으로 나눈 단순화입니다. 실제로는 활성값과 임시 공간, 분할의 불균형 때문에 장치마다 여유가 더 필요합니다.
- 메모리를 줄이는 방법(혼합 정밀도, 활성값 재계산, 작은 마이크로배치)을 먼저 적용하면 분할 없이 해결되는 경우도 있습니다. 다만 모델 상태 자체가 16GiB를 넘으면 배치 조절만으로는 해결되지 않습니다.
- 분할 전략을 고른 뒤에도 GPU 간 연결 속도(NVLink인지 PCIe인지)에 따라 실제 학습 시간은 크게 달라집니다.

## 전체 과정과 연결하기

이번 단원에서는 GPU가 왜 딥러닝에 쓰이는지에서 시작해, CUDA 계층, VRAM과 OOM, 기울기 누적과 혼합 정밀도, 세 가지 병렬 전략까지 살펴보았습니다. 이 미션은 그 판단을 한 번에 연결합니다. 어떤 메모리가 넘치는지 확인하고, 복제할 것과 나눌 것을 정한 뒤, 그 대가로 생기는 통신과 대기를 비교합니다.

기본 데이터 병렬은 각 GPU에 모델 학습 상태 전체를 복제하므로, VRAM 합계가 충분해도 24GiB 상태를 16GiB 장치에 담을 수 없습니다. 레이어 분할이나 텐서 분할로 장치당 상태를 약 12GiB로 낮추면 학습할 수 있으며, 레이어 분할은 경계의 활성값을, 텐서 분할은 레이어마다 부분 결과를 주고받습니다.
