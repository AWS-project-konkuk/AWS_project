## 문제 상황과 전체 맥락

모델을 학습시키는 Python 코드와 리뷰 데이터 파일은 준비했습니다. 하지만 파일이 있다는 사실만으로 학습이 실행되지는 않습니다. **코드를 실행할 컴퓨터**가 필요합니다. 물론 집에 있는 컴퓨터를 사용해도 되지만, 집에 있는 컴퓨터 가지고는 게임도 해야 하고, 인터넷도 봐야하잖아요? 코드를 실행할 전용 컴퓨터가 필요합니다.

## 개념 이해

**EC2 인스턴스는 운영체제와 프로그램을 실행하는 가상 서버**입니다. 내 컴퓨터에서 Python을 실행하듯이, EC2에서도 필요한 환경을 준비하고 학습 프로그램을 실행합니다.

코드가 어떤 일을 하는지는 프로그램이 결정하고, EC2는 그 프로그램이 사용할 실행 자원을 제공합니다. EC2를 켰다는 사실만으로 데이터 준비나 모델 학습이 자동으로 시작되는 것은 아닙니다.

컴퓨터를 구성하는 요소는 다양합니다. **CPU·메모리·GPU** 등이 있죠. 인스턴스 유형에 따라 CPU·메모리·GPU 같은 자원 구성이 달라집니다.

```python
# 실행 환경이 준비된 컴퓨터에서 수행하는 간단한 프로그램입니다.
print("학습 프로그램을 실행할 준비가 되었습니다.")
```

## EC2 사용 예시

1. 학습 코드와 데이터 준비
2. EC2 인스턴스 지정하고 시작시키기
3. 실행 중인 EC2에서 프로그램 시작
4. 데이터 읽기와 학습
5. 결과 파일 생성
6. 사용하지 않는 인스턴스는 중지시키거나 삭제하기

  합니다. EC2는 **단순 컴퓨터를 빌려주는 서비스**입니다.

### 적용 조건과 한계

**EC2를 삭제하면, 안에 있던 데이터는 다 없어집니다.** 그렇기 때문에 데이터를 영구적으로 저장할 수 있는 저장소가 필요합니다. 이는 다음 레슨에서 상세히 배웁니다.

<LessonSummary>

준비한 학습 코드와 입력 파일을 EC2의 실행 환경에서 읽어 계산하면 모델 파일이 만들어집니다. 인스턴스 유형은 계산에 쓸 자원을 결정하고, 프로그램은 그 자원으로 수행할 작업을 결정합니다.

</LessonSummary>
