## 리뷰 파일을 보관하는 곳에서 바로 리뷰 수를 셀 수 있을까요?

저장소에 `reviews.csv`를 올렸습니다. 리뷰 수를 세는 코드 `count_rows.py`는 Git에 기록해 뒀습니다. 코드와 파일을 어디로 보내면 리뷰 수를 확인할 수 있을까요?

## 세 작업 노드의 역할

| 작업 노드              | 역할                                             |
| ---------------------- | ------------------------------------------------ |
| Git의 **코드 저장소**  | 커밋 `a1b2c3d`에서 `count_rows.py`를 제공합니다. |
| 저장소의 **파일 읽기** | 객체 키 `reviews.csv`로 리뷰 파일을 읽습니다.    |
| EC2의 **코드 실행**    | 받은 코드로 파일을 처리하고 리뷰 수를 보냅니다.  |

**시작**은 읽을 파일을 지정합니다. **도착**은 EC2가 보낸 결과를 보여 줍니다. 두 연결은 미리 놓여 있습니다.

## 출력과 입력을 연결하고 실행하기

1. **코드 저장소**의 **실행 코드** 출력을 **코드 실행**의 **실행 코드** 입력에 연결하세요.
2. **파일 읽기**의 **입력 파일** 출력을 **코드 실행**의 **입력 파일** 입력에 연결하세요.
3. **실습 실행**을 누르고 결과에서 **리뷰 3건**을 확인한 뒤 이해 확인에 답하세요.

출력 포트를 먼저 누른 뒤 입력 포트를 눌러도 연결할 수 있습니다. 코드나 파일이 도착하지 않으면 실행 결과에서 어느 입력이 빠졌는지 확인하세요.

<LessonSummary>

Git은 작업에 쓸 코드 버전을 제공하고, 저장소는 입력 파일을 보관합니다. EC2는 두 자료를 받아 실제 계산에 해당하는 작업을 실행합니다. 노드 실습에서는 출력과 입력을 연결해 자료가 어디에서 나와 어느 작업으로 전달되는지 확인합니다. 도착에 표시되는 리뷰 수는 연결한 파일을 읽은 결과입니다.

</LessonSummary>
