## 이번 미션

Git은 v1로 이동했지만 작업 공간의 데이터는 v2입니다. 캐시에 v1이 없을 때 어느 경로로 복원해야 할까요?

## 설계하고 비교할 것

Git 메타데이터와 실제 데이터 경로를 나눠 연결하세요. Git 이동만으로 생긴 불일치를 관찰한 뒤 캐시·원격에서 v1을 복원하세요.

## 실습에서 가져갈 이해

Git은 코드·포인터를, DVC 캐시·원격은 실제 데이터 내용을 관리합니다. 포인터 변경과 복원은 다른 동작입니다.

## 적용 조건과 한계

Git 체크아웃은 메타데이터를 바꾸며 DVC 체크아웃은 캐시의 실제 내용을 작업 공간에 반영합니다. 필요한 내용이 캐시에 없으면 원격에서 가져와야 합니다. 환경·난수·외부 입력까지 고정하지 않으면 동일한 학습 결과는 보장되지 않습니다.

DVC가 추적하는 실제 데이터는 .gitignore로 Git 추적에서 제외합니다. .dvcignore는 DVC가 탐색하지 않을 경로를 지정하는 별도 파일입니다. 캐시는 내용 단위로 재사용하며 모든 바이너리의 변경 바이트만 저장한다고 가정하지 않습니다.

## 전체 과정과 연결하기

Git의 v1 메타데이터로 복원할 내용을 식별하고 로컬 캐시를 확인합니다. 캐시에 없다면 데이터 원격에서 실제 v1 내용을 확보한 뒤 작업 공간에 반영합니다.
