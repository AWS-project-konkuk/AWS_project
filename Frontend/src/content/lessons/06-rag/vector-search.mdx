## 개념 이해

관계형 질의는 가격·분류·정확한 키 같은 조건으로 데이터를 좁히는 데 적합합니다. 벡터 검색은 임베딩의 거리·유사도로 가까운 후보를 찾습니다. 키워드 일치와 의미가 비슷한 것은 같은 기준이 아닙니다.

| 검색 기준   | 예시                       | 주요 판단          |
| ----------- | -------------------------- | ------------------ |
| 조건 일치   | 가격 &lt; 10000, 분류=과일 | 정확한 속성 조건   |
| 벡터 유사도 | 달콤한 과일과 가까운 문서  | 임베딩 공간의 거리 |

## 관찰한 결과 해석하기

RDBMS도 벡터 확장이나 인덱스를 통해 벡터 검색을 지원할 수 있습니다. Vector DB가 RDBMS의 모든 기능을 대체하는 것은 아닙니다. 실제 검색에서는 메타데이터 필터와 유사도 검색을 함께 쓰기도 합니다.

## 적용 조건과 한계

RAG는 검색한 근거의 품질과 생성 모델의 사용 방식에 의존합니다. 차원이 같아도 다른 임베딩 모델의 좌표는 호환되지 않을 수 있습니다. 근거가 없으면 답변을 보류할 수 있어야 하며 환각 제거를 보장하지 않습니다.

## 전체 과정과 연결하기

속성 조건과 키워드로 후보를 좁힐 수도 있고 임베딩의 거리·유사도로 관련 후보를 찾을 수도 있습니다. 벡터 검색은 선택한 표현 공간과 유사도 기준에 따라 순위가 달라집니다.
