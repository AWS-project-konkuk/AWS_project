## 이번 미션

문서와 질문의 임베딩 공간이 다르고 무관한 근거가 검색됩니다.

## 설계하고 비교할 것

문서 준비와 질문 검색을 연결하고 검색 근거가 응답에 미치는 영향을 설명하세요.

## 실습에서 가져갈 이해

Feature Store는 피처의 일관된 제공, 벡터 검색은 관련 문서 조회, RAG는 근거를 생성 문맥에 전달하는 역할입니다. 서로 같은 기능이 아닙니다.

## 적용 조건과 한계

RAG는 검색한 근거의 품질과 생성 모델의 사용 방식에 의존합니다. 차원이 같아도 다른 임베딩 모델의 좌표는 호환되지 않을 수 있습니다. 근거가 없으면 답변을 보류할 수 있어야 하며 환각 제거를 보장하지 않습니다.

## 전체 과정과 연결하기

문서와 질문을 호환되는 벡터 공간으로 준비한 뒤 관련 문서를 검색해 생성 입력으로 전달합니다. 연결이 완성돼도 질문과 무관한 문서가 넘어가면 답변 근거가 부적절해집니다.
