# BlockML 디자인 기준

## 시스템

- Hallmark 2.0.0, modern-minimal, Cobalt. 메인과 레슨은 읽기, 실습과 Playground는 작업 화면이다.
- 기술적이고 차분한 학습 공간. 청회색 바탕, 선명한 본문, 파란색의 선택·실행 신호.
- 실제 강의·실습을 보여준다. 장식 사진, 가짜 지표, 장식용 터미널, 배경 애니메이션은 사용하지 않는다.
- 레슨 주소, 저장 데이터, 완료 조건, 모든 기존 동작을 보존한다.

## 토큰

`src/tokens.css`가 공통 토큰, `src/theme.css`가 기존 색상 이름의 호환 계층이다.

| 역할   | 토큰과 기준                                                                                 |
| ------ | ------------------------------------------------------------------------------------------- |
| 바탕   | `--color-paper`, `--color-paper-2`, `--color-paper-3`                                       |
| 본문   | `--color-ink`, `--color-ink-2`, `--color-muted`                                             |
| 강조   | `--color-accent`, `--color-accent-ink`, `--color-accent-wash`                               |
| 구분선 | `--color-rule`, `--color-rule-2`                                                            |
| 상태   | `--color-error`, `--color-success`                                                          |
| 글꼴   | 기존 자체 제공 Pretendard를 `--font-body`, `--font-display`에 사용. 코드는 `--font-outlier` |
| 간격   | 4px 배수, 관련 요소 8~16px, 영역 24~64px                                                    |
| 모서리 | 화면 패널 8px, 입력·버튼 6px, 중첩 상자 대신 여백·구분선                                    |

## 화면별 구성

- 메인: 넓은 제목과 학습 시작, 진도·학습 방식의 간결한 우측 요약. 아래는 단원별 강의 인덱스. 최대 1312px 콘텐츠.
- 레슨: 272px 목차, 고정 도구 모음, 가운데 65~75ch 읽기 영역. 제목 32~36px, 본문 17px와 1.9 줄간격. 단원·시간은 제목 뒤의 메타 정보. 강의 본문을 먼저 읽고, 전체 워크플로 지도는 본문 뒤에서 참조한다.
- 실습: 기존 읽기·분할·실습 보기 유지. 작업 캔버스는 넓게, 도구와 결과는 안정된 영역에 배치.
- Playground: 노드 목록, 캔버스, 선택 설정을 분명히 나누며 모든 실행 버튼을 유지.

## 조작과 상태

- 기본 실행 버튼은 파란색, 보조 버튼은 중립색. 선택 상태는 파란색 바탕의 옅은 음영과 텍스트로 표시.
- 모든 조작 요소는 즉시 보이는 `:focus-visible`. 비활성은 모양·커서·네이티브 상태를 함께 사용.
- 움직임은 조작 응답에만 사용. `prefers-reduced-motion` 지원. 장식용 움직임 없음.
- 기존 light/dark/system 저장과 선택을 보존한다. 다크는 파란색을 유지한 청회색 톤으로 별도 설계.

## 반응형

1024px 미만에서 목차는 기존 대화상자 패턴을 유지한다. 모바일은 본문·캔버스가 한 열로 흐르며 가로 페이지 넘침을 막는다. 테이블과 작업 캔버스의 자체 스크롤은 허용한다.

## 변경 원칙

일관된 테마·타입·강조색을 공유하고 화면 목적에 따라 배치를 달리한다. 파일·라우트 삭제, 상태 모델 변경은 이 디자인 작업에 포함하지 않는다.
