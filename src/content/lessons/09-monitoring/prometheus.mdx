## 개념 이해

Prometheus는 주기적으로 대상의 지표를 수집하고 시계열로 저장·질의합니다. 요청 수·오류율·지연 같은 시스템 지표와 직접 계측한 모델 관련 지표를 관찰할 수 있습니다.

서비스가 누적 요청 수를 `http_requests_total`이라는 Counter로 노출한다고 가정해 봅니다.

```promql
rate(http_requests_total[5m])
```

이 질의는 최근 5분 표본으로 초당 요청 증가율을 계산합니다. 누적 건수를 그대로 보는 경우와 구분하고, 수집 대상에 해당 메트릭이 존재하는지 확인하세요. [Prometheus 공식 질의 예제](https://prometheus.io/docs/prometheus/latest/querying/examples/)

## 관찰한 결과 해석하기

Prometheus가 모델의 정답을 자동으로 알아내는 것은 아닙니다. 수집 간격이 길면 짧은 변화를 놓칠 수 있고 임계값만으로 원인을 확정할 수 없습니다. 이 페이지는 계측된 예시 지표를 제공하며 실제 서버와 연결하지 않습니다.

## 적용 조건과 한계

입력 분포 변화가 반드시 정확도 하락을 뜻하지는 않습니다. 정답이 늦게 오는 서비스에서는 품질 확인도 지연됩니다. 지표만으로 개별 요청의 원인을 알기 어려우므로 로그·트레이스와 함께 조사합니다.
