## 문제 상황과 전체 맥락

모델을 학습시키는 Python 코드와 리뷰 데이터 파일은 준비했습니다. 하지만 파일이 있다는 사실만으로 학습이 실행되지는 않습니다. 코드를 실행할 컴퓨터가 필요합니다. 이 강의에서는 EC2를 실행할 곳으로, 다음 강의에서는 S3를 데이터를 보관할 곳으로 구분합니다.

## 개념 이해

EC2 인스턴스는 운영체제와 프로그램을 실행하는 가상 서버입니다. 내 컴퓨터에서 Python을 실행하듯이 EC2에서도 필요한 환경을 준비하고 학습 프로그램을 실행합니다. 인스턴스 유형에 따라 CPU·메모리·GPU 같은 자원 구성이 달라집니다.

코드가 어떤 일을 하는지는 프로그램이 결정하고, EC2는 그 프로그램이 사용할 실행 자원을 제공합니다. EC2를 켰다는 사실만으로 데이터 준비나 모델 학습이 자동으로 시작되는 것은 아닙니다.

```python
# 실행 환경이 준비된 컴퓨터에서 수행하는 간단한 프로그램입니다.
print("학습 프로그램을 실행할 준비가 되었습니다.")
```

위 코드는 읽고 복사하는 예제입니다. 이 페이지에서 실제 EC2를 만들거나 Python을 실행하지는 않습니다.

## 관찰한 결과 해석하기

학습 코드와 데이터 준비 → 실행 중인 EC2에서 프로그램 시작 → 데이터 읽기와 학습 → 결과 파일 생성 순서로 생각해 보세요. 프로그램을 실행할 때는 인스턴스가 실행 중이어야 하며, 필요한 환경과 입력 파일도 준비되어 있어야 합니다.

아래 활동에서 시작·중지 상태를 비교할 수 있습니다. 실제 AWS 계정의 인스턴스를 조작하는 실습은 아닙니다.

## 적용 조건과 한계

EC2를 시작하는 것만으로 학습 코드, 패키지와 데이터가 모두 준비되지는 않습니다. 프로그램이 실행될 환경과 파일에 접근할 조건을 확인해야 합니다. 인스턴스의 중지와 종료도 서로 다르므로, 중요한 결과의 보존을 실행 상태에만 의존하지 마세요.

## 전체 과정과 연결하기

전체 지도에서 EC2는 학습 코드를 실행하거나, 학습된 모델을 불러와 예측 프로그램을 실행할 수 있는 곳입니다. 학습과 추론은 서로 다른 작업이며 같은 인스턴스에서 수행해야 하는 것은 아닙니다. 다음 강의에서는 S3의 데이터 읽기 → EC2의 계산 → S3의 결과 저장 흐름을 연결합니다.
